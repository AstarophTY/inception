C'est quoi le projet ? Accéder aux services

01 Le projet en 30 secondes

Inception consiste à bâtir une petite infrastructure de services à la main, chacun isolé dans son conteneur Docker, le tout orchestré avec Docker Compose.

Un reverse proxy NGINX en TLS sert un site WordPress branché sur une base MariaDB. Autour gravitent des services bonus. Comme dans le Spider-Verse : plusieurs entités, un seul univers cohérent. 🕸️

02 Bonus livrés

Redis cache

Object cache WordPress pour soulager MariaDB. Rapide comme Miles en chute libre.

FTP sécurisé

Accès au volume WordPress pour déployer médias et thèmes.

Adminer

Interface web pour inspecter et piloter la base MariaDB.

Gitea

Forge Git auto-hébergée, idéale pour la démo et le versioning.

Site statique

Cette page : une vitrine légère servie par son propre conteneur.

Docker Compose

Réseau dédié, volumes persistants, redémarrage automatique.
